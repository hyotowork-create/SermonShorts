# Sermon Shorts

교회의 설교 영상에서 좋은 대목을 골라 **세로 쇼츠(1080×1920)**로 만드는 데스크톱 앱입니다(Windows·Mac, 무료, MIT).

1. 설교 영상 파일(mp4·mov 등)을 고릅니다.
2. Gemini(본인 API 키)가 설교를 듣고 30~60초 대목 3~5개와 위쪽 제목을 골라 줍니다.
3. 대목마다 자막을 만들고, 시작·끝과 글자를 고칩니다. 미리보기는 실제 쇼츠와 같은 모양입니다.
4. 「선택한 쇼츠 만들기」를 누르면 자막·제목·교회 이름·마지막 안내 장면이 들어간 MP4가 저장됩니다.
5. 업로드 문안(제목·설명·해시태그) 초안도 만들어 줍니다. 업로드는 직접 합니다.

> **지켜 주세요** — 우리 교회 설교만, 설교자 동의를 받고 만드세요. 찬양 부분은 저작권 때문에 넣지 않습니다. AI 자막은 틀릴 수 있으니 올리기 전에 꼭 확인하세요.
> 설교 음성은 Google Gemini로만 가고, 영상 파일은 이 컴퓨터 밖으로 나가지 않습니다. API 키는 운영체제 보안 저장소에 암호화해 보관합니다.

## 내려받기

[Releases](https://github.com/hyotowork-create/SermonShorts/releases/latest)에서 운영체제에 맞는 파일을 받습니다.

| 운영체제 | 파일 |
|---|---|
| Windows 10·11 (64비트) | `Sermon-Shorts-Setup-버전.exe`(설치판) 또는 `Sermon-Shorts-버전-portable.exe`(설치 없이 실행) |
| Mac (Apple Silicon M1~) | `Sermon-Shorts-버전-arm64.dmg` |
| Mac (Intel) | `Sermon-Shorts-버전.dmg` |

Gemini API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 만들고, 앱 오른쪽 위 「설정」에 넣습니다.

## Windows에서 설치할 때 나올 수 있는 메시지

이 앱은 유료 코드 서명 인증서가 없어서, 처음 실행할 때 Windows가 경고를 띄웁니다. 아래 순서대로 하면 됩니다.

| 나오는 메시지 | 이유 | 이렇게 하세요 |
|---|---|---|
| **「Windows의 PC 보호」**(파란 창, Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 차단했습니다) | 새로 나온 앱이라 내려받은 사람이 적어 Microsoft가 아직 모름 | 창 안의 **「추가 정보」**를 누름 → 아래에 생기는 **「실행」**을 누름. 한 번만 하면 됩니다 |
| 브라우저가 **「일반적으로 다운로드되지 않는 파일」**, **「이 파일은 위험할 수 있습니다」** 라며 받기를 막음(Edge·Chrome) | 위와 같은 이유 | Edge: 다운로드 목록에서 파일의 **⋯ → 유지 → 자세히 표시 → 그래도 유지**. Chrome: **⋮ → 위험한 파일 다운로드** |
| **「Windows에서 PC를 보호했습니다」 다음에 「실행」 버튼이 없음** | 회사·교회 PC에서 관리자가 SmartScreen을 강제로 켜 둠 | 관리자에게 허용을 요청하거나, 개인 PC에서 설치. 또는 portable 파일을 써 보세요 |
| 백신(V3·알약·Defender 등)이 **파일을 지우거나 「위협 발견」** | 서명 없는 새 실행 파일을 의심하는 오진 | 백신의 검역소(치료함)에서 **「복원」·「예외 추가」**. 파일이 정상인지는 아래 「파일 확인」으로 지문을 비교할 수 있습니다 |
| **「이 앱은 PC에서 실행할 수 없습니다」** | 32비트 Windows 또는 ARM(서피스 프로 X 등) Windows | 64비트(x64) Windows 10·11에서만 됩니다. `설정 → 시스템 → 정보 → 시스템 종류`에서 「64비트 운영 체제, x64 기반 프로세서」인지 확인 |
| **「이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?」**(사용자 계정 컨트롤) | 설치 폴더에 쓰기 위해 | 설치판이 맞으면 **「예」**. 관리자 권한이 없으면 설치 화면에서 「현재 사용자만」을 고르세요 |
| 설치는 됐는데 **아무 창도 안 뜸** | 이전 실행이 백그라운드에 남음 | 작업 관리자(Ctrl+Shift+Esc)에서 `Sermon Shorts`를 끝낸 뒤 다시 실행. 그래도 안 되면 PC 재시작 |
| 쇼츠를 만들 때 **「영상 처리에 실패했습니다」** | 영상 파일이 깨졌거나, 저장 폴더에 쓸 권한이 없음 | 저장 폴더를 「동영상」이나 바탕화면으로 바꿔 보세요. 다른 영상으로도 같으면 아래 「문의」로 알려 주세요 |
| **「Gemini API 키가 맞지 않습니다」**, **「사용 한도를 넘었습니다」** | 키를 잘못 붙여 넣었거나 무료 한도 초과 | 설정에서 키를 다시 붙여 넣기(앞뒤 빈칸 없이). 한도는 잠시 뒤 다시 하면 풀립니다 |

**파일 확인(선택)**: 받은 파일이 릴리스 파일과 같은지 보려면 PowerShell에서 `Get-FileHash .\파일이름.exe` 를 실행해 릴리스 설명의 SHA256 값과 비교하세요.

## Mac에서 처음 열 때

Apple 공증을 받지 않은 앱이라 처음 열면 「확인되지 않은 개발자」 또는 「열 수 없습니다」가 뜹니다. **시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 「그래도 열기」**를 한 번 누르면 됩니다.

## 개발

```bash
npm install
npm start                       # 실행
SERMON_SHORTS_MOCK=1 npm start  # AI 없이 가짜 결과로 화면·렌더 시험
npm test                        # 점검
npm run build:mac               # dmg / build:win 은 Windows에서
```
